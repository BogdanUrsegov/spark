# Spark — Telegram-бот знакомств

## Возможности

- Анкеты с возрастом, полом и геопозицией; можно добавить до трёх фото и/или видео длительностью до 30 секунд, описание необязательно.
- Просмотр анкет, лайки, дизлайки и послания.
- Уведомления о лайках и взаимной симпатии.
- Фильтрация по полу, статус поиска и административные команды.
- Админ-панель: статистика, список пользователей, информация по ID, бан/разбан, рассылка и удаление анкет.
- Администратор вручную создаёт тестовые анкеты, делясь геопозицией через кнопку Telegram; город определяется автоматически. Можно добавить до трёх фото и/или видео длительностью до 30 секунд, а описание — пропустить. Тестовые анкеты участвуют в обычном геопоиске наравне с остальными анкетами, с теми же фильтрами возраста, пола и расстояния. Они не являются Telegram-аккаунтами: взаимодействия с ними выглядят как обычно, но лайки и послания не доставляются и не вызывают уведомлений; такие анкеты не включаются в рассылки или списки реальных пользователей.
- SQLite и запуск через Docker Compose.

## Запуск через Docker Compose

1. Установите Docker и Docker Compose.
2. Создайте локальный конфигурационный файл из примера:

   ```bash
   cp config/.env.example config/.env
   ```

3. Заполните `BOT_TOKEN`, `ADMIN_ID` и `TELEGRAM_LOG_CHANNEL_ID` в `config/.env`.
4. Запустите приложение:

   ```bash
   docker compose up -d --build
   ```

Локальный файл `config/.env` не должен попадать в Git. База по умолчанию создаётся в `data/database.db`; для Docker Compose каталог `data` подключён как постоянный том. Путь можно переопределить переменной `PATH_DB`.

## Запуск локально

Создайте и активируйте виртуальное окружение, установите зависимости и выполните `python main.py` из корня проекта. Конфигурация загружается из `config/.env`.

## Безопасность

- Никогда не коммитьте токен Telegram-бота или реальные конфигурационные файлы.
- Если токен когда-либо был опубликован, отзовите его через BotFather и выпустите новый. Удаление файла в новом коммите не очищает историю Git.
- Логи не должны содержать тексты личных посланий и другие чувствительные данные.
